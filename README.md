# Head First Design Patterns Java Practice

Head First Design Patterns를 읽으며 디자인 패턴을 Java로 직접 구현해보는 학습용 저장소입니다.

## 목표

- 각 디자인 패턴이 해결하려는 문제 이해
- 책 예제를 직접 구현
- 내 프로젝트 상황에 맞는 예제로 변형
- 패턴 적용 전/후 코드 비교
